# Yarn Fever 🧶

A cozy 3D unravel puzzle PWA. Tap loose pieces of the knitted castle — their yarn
winds into a matching basket. Three of a kind clears the basket. Yarn with no
basket waits in the buffer row; if it fills up, you're stuck.

- Endless procedural levels (harder every 5th — 💀)
- Boosters: 🔨 unravel anything, ✂️ auto-fill a basket, 🖌️ reshuffle colors
- Coin economy, unlockable 3rd/4th baskets + 6th buffer slot, daily gift
- Works offline, installable to home screen

Stack: three.js r160 (CDN, service-worker cached), vanilla JS, zero build step.
